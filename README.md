# Game

This repository contains a simple platformer. You can run it either in Python using Pygame or directly in your browser.

## Play in your browser

Open `platform_game.html` in any modern browser. Use the left/right arrow keys to move and press space to jump.

## Run with Pygame (optional)

1. Install dependencies:
   ```bash
   pip install pygame
   ```
2. Launch the game:
   ```bash
   python platform_game.py
   ```

Use the left and right arrow keys to move. Press space to jump.
